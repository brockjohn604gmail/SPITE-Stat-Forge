The Companion Metrics Toolkit provides a **configuration surface** for adjusting progression-related variables within supported environments. It offers granular control over:

- **SP (Skill Points) earning multipliers** — scale gains to match your preferred pacing.
- **STA (Stamina) regeneration curves** — smooth out the peaks and valleys of energy management.
- **Mini-event bypass logic** — optionally skip time-consuming mini-games with a single toggle.
- **Stat rebalancing presets** — curated profiles inspired by the Boss's Wife, Sister, and Mother archetypes.
- **Session analytics** — visualize how your adjustments affect overall progression velocity.

Everything is handled through a clean, human-readable configuration layer, audited for stability and reversibility.

## 🧠 Conceptual Architecture

The toolkit sits atop a three-layer model:

- **Perception Layer** — reads environment state without altering it.
- **Translation Layer** — maps user intent (sliders, presets, toggles) into structured directives.
- **Application Layer** — applies directives through sanctioned configuration interfaces.

This separation ensures that even aggressive tuning profiles never corrupt underlying data structures.
